## 快速开始

1. 根据上面的目录导航进入目标主题。
2. 下载对应的 Multisim 工程文件。
3. 使用与文件版本匹配的 Multisim 打开并运行仿真。

仓库中的工程文件主要使用以下格式：

| 扩展名 | 适用版本 |
| --- | --- |
| `.ms14` | Multisim 14 |
| `.ms9` | Multisim 9 |
| `.ms8` | Multisim 8 |

不同版本之间可能存在元件库、模型或工程格式兼容性差异。如果文件无法直接打开，建议使用对应版本的 Multisim，或在打开后重新检查元件模型与仿真参数。

## 说明

- 文件名带有 `Security copy` 的文件是 Multisim 自动生成的备份副本，通常优先打开同名的原始工程文件即可。
- 部分案例来自不同阶段的学习与设计记录，仿真参数和元件模型可能需要根据实际应用重新校核。
- 仿真结果仅供学习和方案验证参考，实际电路应用前请结合器件手册、工作条件和安全裕量进行测试。
